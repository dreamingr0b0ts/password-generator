# Random Password Generator

This Python script creates a secure, random password using letters, numbers, and symbols. It's great for creating strong passwords for your accounts or systems.

## Requirements

- Python 3.x
- No external libraries needed

## Usage

Run the script:

```bash
python password_generator.py
```

You'll see output like:

```
Generated password: aG7#vK!2wP9x
```

## Why Use It?

- Instantly generate complex passwords
- No need to rely on browser password managers
- Customizable for future expansion (length, symbols, etc.)
